## 확정된 항목 (2026-11-17)

1. 2026년 증권거래세율: 코스피 거래세 0.05% + 농특세 0.15%, 코스닥 0.20% (2026-01-01 시행 세법 기준)
2. 계정과목 체계 v1: 수수료는 취득원가에 넣지 않고 비용 처리 (FVPL)
3. 매도 원가의 원 미만 금액: 절사, 잔여 원가가 흡수
4. 저장소 공개 범위: 예시 전략 1개만 공개, 개인 전략은 제외

## 남은 실측 항목 (Phase 2)

- 확인 (2026-11-18, 069500 1주 80,540원 매수): 모의계좌도 수수료를 차감한다(10원, 10원 미만 절사). D+2 예수금은 `prvs_rcdl_excc_amt`, D+0은 `dnca_tot_amt`, D+1은 `nxdy_excc_amt`.
- 확인 (2026-11-20 결제일): `dnca_tot_amt`가 100,000,000 → 99,919,450으로 줄었고 원장 예수금과 일치했다 (대사 1일차 무오류).
- 남음: 모의계좌 수수료율 (10원 절사 때문에 0.014%와 0.015%를 구분하려면 100만 원 안팎 거래가 필요), 매도 시 세금 차감.
