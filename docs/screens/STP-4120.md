# STP-4120 마스터 적재 내역

> 이 문서는 `src/ministp/ui/screens/STP-4120.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 기준정보 > 종목

## 목적

master load가 종목 마스터를 넣은 날마다 한 줄이에요. 그날 파일의 종목 수, 신규·변경·빠짐 건수, 받은 두 파일의 해시가 남아 있어요. 왼쪽에서 적재를 고르면 그날 바뀐 종목과 바뀐 항목이 오른쪽에 나오고, 종목을 두 번 누르면 시장 종목 마스터(STP-4110)에서 그 종목의 이력을 열어요. 가격 변동은 여기 나오지 않아요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 46%): `loads` 적재 기록
- 오른쪽: `changes` 이 적재에서 바뀐 종목

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP4120R01` | 마스터 적재 기록 | `date_from` (date), `date_to` (date), `load_id` (int) | loads |
| `STP4120R02` | 적재에서 바뀐 종목 | `load_id` (int), `change` (text) | changes |

## 그리드 `loads` 적재 기록

- 트랜잭션: `STP4120R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 실시간: DB가 바뀌면 마지막 조회조건으로 다시 조회, 바뀐 칸 강조 (행 식별 열 `load_id`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `load_id` | 적재 번호 | master_loads.load_id | 적재 번호 | 수량 | 오른쪽 |  |  |
| `base_date` | 기준일 | master_loads.base_date | 기준일 (파일을 받은 날) | 날짜 | 왼쪽 |  |  |
| `rows_total` | 종목 수 | master_loads.rows_total | 종목 수 | 수량 | 오른쪽 |  |  |
| `rows_new` | 신규 | master_loads.rows_new | 신규 (처음 나타난 종목 수) | 수량 | 오른쪽 |  |  |
| `rows_changed` | 변경 | master_loads.rows_changed | 변경 (속성이 바뀐 종목 수) | 수량 | 오른쪽 |  |  |

## 그리드 `changes` 이 적재에서 바뀐 종목

- 트랜잭션: `STP4120R02` → 데이터셋 `main`
- 불러오는 때: 목록(마스터)에서 행 선택
- 마스터: `loads` (`load_id` ← `loads.load_id`)
- 행 더블클릭·Enter: STP-4110로 이동 (`keyword` ← `symbol`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `symbol` | 단축코드 | instrument_master.symbol | 단축코드 | 코드 | 왼쪽 |  | `name` 배지 안에 표시 |
