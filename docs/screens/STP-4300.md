# STP-4300 기준정보

> 이 문서는 `src/ministp/ui/screens/STP-4300.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 기준정보 > 거래 기준

## 목적

원장과 주문 검증이 실제로 쓰는 기준값(수수료·세율, 결제주기, 호가단위, 휴장일, 주문 검증 기준)을 한곳에서 보여줘요. 화면에 따로 저장한 값이 아니라 시스템이 계산에 쓰는 객체에서 바로 읽어서, 화면과 계산이 어긋날 수 없어요. 변경은 게이트 이후 적용시작일이 있는 이력으로 추가할 예정이에요.
