# STP-1400 고객별 보유

> 이 문서는 `src/ministp/ui/screens/STP-1400.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 주문·잔고 > 고객별 보유

## 목적

왼쪽에서 고객을 고르면 오른쪽에 그 고객의 계좌를 모두 더한 종목별 보유와, 그 고객의 계좌 목록이 나와요. 한 고객이 계좌를 여러 개 가질 때 고객 단위로 얼마를 들고 있는지 보는 화면이에요. 계좌를 더블클릭하면 그 계좌의 계좌정보(STP-3400)로 가요. 고객 정보는 별칭뿐이고 실명 같은 개인정보는 DB에 없어요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 40%): `customers` 고객
- 오른쪽: `positions` 이 고객의 보유 합산 (계좌를 더한 값), `accounts` 이 고객의 계좌

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP1400R01` | 고객 목록 | 없음 | customers |
| `STP1400R02` | 고객 보유 합산 | `customer_id` (text) | positions |
| `STP1400R03` | 고객의 계좌 | `customer_id` (text) | accounts |

## 그리드 `customers` 고객

- 트랜잭션: `STP1400R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 합계: `cash_d0`, `book_cost`
- 실시간: DB가 바뀌면 마지막 조회조건으로 다시 조회, 바뀐 칸 강조 (행 식별 열 `customer_id`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `customer_id` | 고객 ID | customers.customer_id | 고객 ID | 코드 | 왼쪽 |  |  |
| `alias` | 고객 별칭 | customers.alias | 고객 별칭 | 문자 | 왼쪽 |  |  |
| `accounts` | 계좌 수 | - | (화면 계산·집계 값) | 수량 | 오른쪽 |  |  |
| `cash_d0` | 예수금 합계 | - | (화면 계산·집계 값) | 금액 | 오른쪽 |  |  |
| `book_cost` | 보유 장부금액 합계 | - | (화면 계산·집계 값) | 금액 | 오른쪽 |  |  |

## 그리드 `positions` 이 고객의 보유 합산 (계좌를 더한 값)

- 트랜잭션: `STP1400R02` → 데이터셋 `main`
- 불러오는 때: 목록(마스터)에서 행 선택
- 마스터: `customers` (`customer_id` ← `customers.customer_id`)
- 높이 비중: 2 (좌우 구성에서 같은 쪽 그리드와 나눠 쓰는 높이)
- 합계: `book_cost`

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `instrument_name` | 종목명 | instruments.name | 종목명 | 문자 | 왼쪽 |  | 배지(이름 첫 글자, 색은 코드·모양은 자산 유형) |
| `symbol` | 종목코드 | customer_positions_v.symbol | 종목코드 | 코드 | 왼쪽 |  | `instrument_name` 배지 안에 표시 |
| `asset_type` | 자산 유형 | instruments.asset_type | 자산 유형 (STOCK / ETF) | 코드 | 왼쪽 |  | `instrument_name` 배지 안에 표시 |
| `qty` | 보유수량 | customer_positions_v.qty | 보유수량 | 수량 | 오른쪽 |  |  |
| `book_cost` | 장부금액 | customer_positions_v.book_cost | 장부금액 (매입금액) | 금액 | 오른쪽 |  |  |
| `accounts` | 보유 계좌 수 | - | (화면 계산·집계 값) | 수량 | 오른쪽 |  |  |
