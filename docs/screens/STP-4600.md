# STP-4600 코드 관리

> 이 문서는 `src/ministp/ui/screens/STP-4600.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 기준정보 > 공통코드

## 목적

시스템에 코드로 들어 있는 값과 그 이름을 한곳에서 봐요. 왼쪽에서 코드 그룹을 고르면 오른쪽에 그 그룹의 코드와 코드명이 나와요. 계정과목은 원장 분개가 직접 참조하는 코드라서 전용 테이블에 있고, 나머지는 공통코드예요. 공통코드가 스키마 제약, 프로그램, 저장된 값과 어긋나면 "스키마·프로그램과 일치"가 아니오로 바뀌어요. 코드명 변경, 코드 추가, 사용 여부 변경은 그리드 오른쪽 위 버튼으로 해요 (CLI의 code 명령과 같은 처리). 프로그램이 정한 그룹은 코드명만 바꿀 수 있고, 코드는 지우지 않고 사용 안 함으로 꺼요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 48%): `groups` 코드 그룹
- 오른쪽: `codes` 이 그룹의 코드

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP4600R01` | 코드 그룹 목록 | 없음 | groups |
| `STP4600R02` | 그룹의 코드 | `group_id` (text) | codes |

## 처리 트랜잭션

처리 버튼이 부르는 트랜잭션이에요. CLI 명령과 같은 함수를 부르고, 화면 서버를 처리 가능으로 열었을 때만 동작해요.

| 트랜잭션 | 이름 | 입력 | 부르는 버튼 |
|---|---|---|---|
| `STP4600U01` | 코드 그룹 추가 | `group_id` (text), `name` (text), `description` (text, 선택) | groups · 그룹 추가 |
| `STP4600U02` | 코드 추가 | `group_id` (text), `code` (text), `name` (text), `description` (text, 선택) | codes · 코드 추가 |
| `STP4600U03` | 코드명 변경 | `group_id` (text), `code` (text), `name` (text), `description` (text, 선택) | codes · 코드명 변경 |
| `STP4600U04` | 코드 사용 여부 변경 | `group_id` (text), `code` (text), `in_use` (text) | codes · 사용 여부 |

## 그리드 `groups` 코드 그룹

- 트랜잭션: `STP4600R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 상태 표시: 스키마·프로그램과 일치 (`consistent`)
- 실시간: DB가 바뀌면 마지막 조회조건으로 다시 조회, 바뀐 칸 강조 (행 식별 열 `group_id`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `group_id` | 코드 그룹 ID | code_groups.group_id | 코드 그룹 ID | 코드 | 왼쪽 |  |  |
| `name` | 코드 그룹명 | code_groups.name | 코드 그룹명 | 문자 | 왼쪽 |  |  |
| `store` | 관리 위치 | - | (화면 계산·집계 값) | 문자 | 왼쪽 |  |  |
| `codes` | 코드 수 | - | (화면 계산·집계 값) | 수량 | 오른쪽 |  |  |
| `used_by` | 쓰는 곳 | code_groups.used_by | 쓰는 곳 (이 코드를 저장하는 테이블.컬럼) | 코드 | 왼쪽 |  |  |
