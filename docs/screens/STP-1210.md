# STP-1210 주식 주문

> 이 문서는 `src/ministp/ui/screens/STP-1210.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 주문·잔고 > 주문·체결

## 목적

주문을 한 줄씩 쓰고, 체크한 줄을 한 번에 결재 요청해요(R-99~102). 오른쪽 "선택 묶음 검증"은 체크한 줄을 보낼 순서대로 쌓고 이미 잡힌 요청(결재 대기, 승인 후 미전송)과 미체결 주문까지 더해서 다시 본 결과예요(R-98). 한 줄씩은 통과해도 묶음으로 보면 예수금이나 비중이 모자랄 수 있어서, 줄마다 단건과 묶음 결과를 함께 보여 줘요. 묶음이 불합격이거나 작성 권한이 없으면 결재 요청이 잠기고, 셀프 승인 허용이 있는 승인 권한이 없으면 "승인하고 전송"이 잠겨요. 쓴 줄은 저장하지 않아요. 요청한 줄은 아래 목록에 남고, 승인되면 장중 `run`이 다시 검증한 뒤 보내요. 요청 번호는 주문일마다 1부터 매기는 순번이고, 단건은 줄마다 요청 1건, 바스켓(STP-1500)에서 가져온 줄(BK)은 함께 체크해서 요청 1건(주문 유형 바스켓)이 되고 그 안에 줄 번호가 붙어요. 바스켓은 전부 아니면 전무로 결재돼요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 64%): `lines` 주문 작성
- 오른쪽: `set` 선택 묶음 검증, `history` 결재·전송 이력

## 그리드 `lines` 주문 작성

- 트랜잭션: `STP1210R01` → 데이터셋 `main`
- 불러오는 때: 조회조건을 바꿀 때마다 (입력 즉시 재계산)
- 높이 비중: 3 (좌우 구성에서 같은 쪽 그리드와 나눠 쓰는 높이)
- 체크박스: 행 앞의 체크박스로 여러 행을 골라요. 체크한 행의 키(`key`)를 쉼표로 이어 `picked`로 보내요(그 값을 받는 그리드는 체크를 바꿀 때마다 다시 계산). `pickable`이 참인 행만 체크할 수 있어요. `group` 값이 같은 행은 함께 체크되고 함께 풀려요(묶음은 전부 아니면 전무). 머리의 체크박스는 모두 체크·해제, 행에서 스페이스로도 체크해요
- 화면에서 쓰는 줄: `＋ 줄 추가` 버튼의 입력 창으로 한 줄씩 더해요(저장하지 않음, 더한 줄은 체크된 채로 들어와요). 줄은 `줄번호:symbol:side:qty:limit_price`을 쉼표로 이어 `lines`로 보내요. `줄 빼기` 버튼은 체크한 쓴 줄을 빼요. 다른 화면이 주소의 `lines`로 줄을 넘기면 그 줄들이 체크된 채로 들어와요
- 상태 표시: 주문일 (`order_date`), 사용자 (`user`)

### 처리 버튼 `request` 결재 요청

- 위치: 그리드 오른쪽 위
- 처리 트랜잭션: `STP1210U01` 결재 요청
- 대상: 행을 고르지 않아도 됨
- 안내: 체크한 줄을 결재 대기로 올려요. 승인자가 STP-5100에서 승인하면 장중 run이 다시 검증하고 보내요. 서버가 묶음 검증과 권한을 한 번 더 봐요.
- 그리드가 채우는 입력: `picked`, `lines` (체크한 행, 화면에서 쓴 줄)
- 잠금: 트랜잭션 `STP1210R01`의 상태값 `request_lock`이 비어 있지 않으면 잠기고 그 글이 이유로 보여요. 서버는 누를 때 같은 검사를 다시 해요
- 끝나면: 화면에서 쓴 줄 가운데 체크한 줄을 지워요 (요청으로 넘어갔으니까)
- 입력 창: 입력 항목 없이 확인만 받아요

### 처리 버튼 `send` 승인하고 전송

- 위치: 그리드 오른쪽 위
- 처리 트랜잭션: `STP1210U02` 결재 요청하고 셀프 승인
- 대상: 행을 고르지 않아도 됨
- 안내: 결재 요청과 셀프 승인을 한 번에 해요. 셀프 승인 허용이 있는 승인 권한과 1건 한도 안에서만 돼요. 승인되면 장중 run이 다시 검증하고 바로 보내요.
- 그리드가 채우는 입력: `picked`, `lines` (체크한 행, 화면에서 쓴 줄)
- 잠금: 트랜잭션 `STP1210R01`의 상태값 `send_lock`이 비어 있지 않으면 잠기고 그 글이 이유로 보여요. 서버는 누를 때 같은 검사를 다시 해요
- 끝나면: 화면에서 쓴 줄 가운데 체크한 줄을 지워요 (요청으로 넘어갔으니까)
- 입력 창: 입력 항목 없이 확인만 받아요
