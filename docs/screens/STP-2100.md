# STP-2100 일일 대사 결과

> 이 문서는 `src/ministp/ui/screens/STP-2100.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 대사·평가 > 대사

## 목적

왼쪽 달력에서 날마다의 대사 결과와 게이트까지 남은 날을 한눈에 보고, 날짜를 누르면 오른쪽에 그날의 항목별 내부 값과 증권사 값, 불일치와 판단 이력이 나와요. 달력은 불일치가 있던 날만 색으로 표시해요(빨강 불일치, 노랑 불일치를 모두 판단한 날). 그날 목록은 판단 전 불일치, 판단한 불일치, 일치 순이라 보유 종목이 많아도 불일치가 맨 위에 있어요. 대사 항목은 예수금 D+0·D+2(계좌 전체), 체결 수량(일자), 보유 수량·장부금액(종목) 다섯 가지예요. 불일치 행을 고르고 오른쪽 위 원인 판단 버튼을 누르면 판단을 기록해요 (CLI의 resolve 명령과 같은 처리). 불일치 행은 고치지 않고 판단을 새 행으로 덧붙여요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 32%): `days` 대사 달력
- 오른쪽: `results` 그날의 대사 결과

## 그리드 `days` 대사 달력

- 트랜잭션: `STP2100R02` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 표시: 달력 (하루가 한 칸, 날짜 `date`, 칸 색 `state`). 달마다 한 덩어리로 오래된 달부터 그리고, 나머지 열은 칸에 마우스를 올리면 보여요. 칸을 누르면 그날이 골라져요 (←→ 하루, ↑↓ 한 주)
- 상태 표시: 무오류 연속 영업일 (`clean_streak`), 게이트까지 남은 날 (`gate_left`)

### 처리 버튼 `resolve` 원인 판단

- 위치: 그리드 오른쪽 위
- 처리 트랜잭션: `STP2100U01` 불일치 원인 판단
- 대상: 고른 행 (`status`가 BREAK일 때만)
- 입력 창 위에 보여 주는 행의 값: `item_name`, `key`, `diff`
- 안내: 불일치 행은 고치지 않아요. 판단이 새 행으로 덧붙고, 다시 판단하면 가장 나중 것이 보여요 (R-73).

| 입력 항목 | 한글명 | 형식 | DB 컬럼 | 필수 | 처음 값 | 선택값 | 찾기 팝업 |
|---|---|---|---|---|---|---|---|
| `result_id` | 행 번호 | text | recon_results.id | 예 | 행의 `id` (고칠 수 없음) |  |  |
| `cause` | 원인 코드 | text | recon_results.cause_code | 예 |  |  | `code` (group_id=RECON_CAUSE) |
| `note` | 판단 메모 | text | recon_results.note | 예 |  |  |  |
