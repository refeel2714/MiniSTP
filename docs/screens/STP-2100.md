# STP-2100 일일 대사 결과

> 이 문서는 `src/ministp/ui/screens/STP-2100.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

## 목적

대사 항목별 내부 값과 증권사 값, 불일치와 그에 대한 판단 이력을 함께 봐요. 판단 기록은 resolve 명령으로만 해요.

## 조회조건

| 조건 | 한글명 | 형식 | DB 컬럼 | 기본값 | 선택값 |
|---|---|---|---|---|---|
| `date_from` | 시작일 | date | - |  |  |
| `date_to` | 종료일 | date | - |  |  |
| `kind` | 유형 | select | broker_snapshots.kind | DAILY_RECON | DAILY_RECON, INTRADAY_RECON |
| `only_breaks` | 불일치만 | bool | - |  |  |

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP2100R01` | 대사 결과 | `date_from` (date), `date_to` (date), `kind` (text), `only_breaks` (bool) | results |
