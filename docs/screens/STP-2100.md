# STP-2100 일일 대사 결과

> 이 문서는 `src/ministp/ui/screens/STP-2100.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

## 목적

대사 항목별 내부 값과 증권사 값, 불일치와 그에 대한 판단 이력을 함께 봐요. 불일치 행을 고르고 오른쪽 위 원인 판단 버튼을 누르면 판단을 기록해요 (CLI의 resolve 명령과 같은 처리). 불일치 행은 고치지 않고 판단을 새 행으로 덧붙여요.

### 처리 버튼 `resolve` 원인 판단

- 위치: 그리드 오른쪽 위
- 처리 트랜잭션: `STP2100U01` 불일치 원인 판단
- 대상: 고른 행 (`status`가 BREAK일 때만)
- 입력 창 위에 보여 주는 행의 값: `date`, `item`, `key`, `diff`
- 안내: 불일치 행은 고치지 않아요. 판단이 새 행으로 덧붙고, 다시 판단하면 가장 나중 것이 보여요 (R-73).

| 입력 항목 | 한글명 | 형식 | DB 컬럼 | 필수 | 처음 값 | 선택값 | 찾기 팝업 |
|---|---|---|---|---|---|---|---|
| `result_id` | 행 번호 | text | recon_results.id | 예 | 행의 `id` (고칠 수 없음) |  |  |
| `cause` | 원인 코드 | select | recon_results.cause_code | 예 |  | MISSING_EXEC, FEE_DIFF, TAX_DIFF, ROUNDING, CORP_ACTION, TIMING, UNKNOWN |  |
| `note` | 판단 메모 | text | recon_results.note | 예 |  |  |  |
