# STP-4500 분개 모형

> 이 문서는 `src/ministp/ui/screens/STP-4500.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 기준정보 > 회계 기준

## 목적

원장이 이벤트 유형마다 어떤 전표를 만드는지 보여줘요. 왼쪽에서 모형을 고르면 오른쪽에 그 전표의 줄(차변·대변, 계정, 금액 산식, 업무 규칙)과 참고 한 줄이 나와요. 화면에 따로 저장한 표가 아니라 원장 코드의 규칙을 옮긴 표이고, 무작위로 만든 장부의 전표가 모두 이 표의 모형 하나에 들어맞는지 시험이 매번 확인해요. 모형을 두 번 누르면 그 이벤트 유형의 실제 분개를 분개 조회(STP-3200)에서 열어요. 모형을 DB 테이블로 옮겨 원장이 읽게 하는 것은 게이트 뒤예요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 50%): `templates` 분개 모형
- 오른쪽: `lines` 모형의 줄

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP4500R01` | 분개 모형 | 없음 | templates |
| `STP4500R02` | 분개 모형의 줄 | `code` (text) | lines |

## 그리드 `templates` 분개 모형

- 트랜잭션: `STP4500R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 행 더블클릭·Enter: STP-3200로 이동 (`event_type` ← `event_type`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `code` | 모형 | - | (화면 계산·집계 값) | 코드 | 왼쪽 |  |  |
| `event_type` | 이벤트 유형 | ledger_events.event_type | 이벤트 유형 | 코드 | 왼쪽 |  | 코드명(공통코드 `EVENT_TYPE`) |
| `kind` | 전표 유형 | journal_entries.kind | 전표 유형 | 문자 | 왼쪽 |  | 숨김 (행 식별·연결에만 씀), 코드명(공통코드 `JOURNAL_KIND`) |
| `kind_name` | 전표 유형 | - | (화면 계산·집계 값) | 문자 | 왼쪽 |  |  |
| `case` | 조건 | - | (화면 계산·집계 값) | 문자 | 왼쪽 |  |  |
| `shape` | 전표 모양 | - | (화면 계산·집계 값) | 문자 | 왼쪽 |  | 숨김 (행 식별·연결에만 씀) |
| `line_count` | 줄 수 | - | (화면 계산·집계 값) | 수량 | 오른쪽 |  |  |
| `note` | 참고 | - | (화면 계산·집계 값) | 문자 | 왼쪽 |  | 숨김 (행 식별·연결에만 씀) |

## 그리드 `lines` 모형의 줄

- 트랜잭션: `STP4500R02` → 데이터셋 `main`
- 불러오는 때: 목록(마스터)에서 행 선택
- 마스터: `templates` (`code` ← `templates.code`)
- 상태 표시: 조건 (`case`), 참고 (`note`)

| `account_name` | 계정명 | accounts_chart.name | 계정명 | 문자 | 왼쪽 |  |  |
| `amount` | 금액 산식 | - | (화면 계산·집계 값) | 문자 | 왼쪽 |  |  |
