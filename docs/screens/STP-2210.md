# STP-2210 기준가 이력

> 이 문서는 `src/ministp/ui/screens/STP-2210.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 대사·평가 > 기준가

## 목적

날마다 낸 기준가의 기록이에요. 왼쪽은 기준일마다 기준가(1,000좌당), 전일 대비, 순자산, 그날 기준가를 낸 횟수예요(같은 날 다시 내면 마지막 값이 그날의 기준가이고 횟수가 2 이상이 돼요). 기준일을 고르면 오른쪽에 변동 상세가 나와요. 전일 순자산에서 당일 순자산까지를 위에서 아래로 읽는 표이고, 그 사이에 기록된 분개를 계정별로 더한 값이에요. 순자산은 들고 있는 것에서 따로 세기 때문에 둘이 맞으면 설명되지 않은 차이가 0이고 검증이 일치예요. 불일치인 날이 있으면 그날이 먼저 골라져 있어요. 기준일을 두 번 누르면 그날의 분개를 분개 조회(STP-3200)에서 열어요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 52%): `days` 기준일별 기준가
- 오른쪽: `bridge` 변동 상세

## 그리드 `days` 기준일별 기준가

- 트랜잭션: `STP2210R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 상태 표시: 모두 설명됨 (`all_explained`), 설명 안 된 날 수 (`unexplained_days`)
- 행 더블클릭·Enter: STP-3200로 이동 (`date_from` ← `date`, `date_to` ← `date`)
- 실시간: DB가 바뀌면 마지막 조회조건으로 다시 조회, 바뀐 칸 강조 (행 식별 열 `date`)

| `nav_per_1000` | 기준가 | - | (화면 계산·집계 값) | 비율·단가 | 오른쪽 |  |  |

- 불러오는 때: 목록(마스터)에서 행 선택
- 마스터: `days` (`date` ← `days.date`)
