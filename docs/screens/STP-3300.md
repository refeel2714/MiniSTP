# STP-3300 시산표

> 이 문서는 `src/ministp/ui/screens/STP-3300.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 원장·회계 > 시산표

## 목적

계정과목별 잔액을 한 표로 보여줘요. 장부 전체의 차변 합계와 대변 합계가 같은지를 표 위에 함께 보여줘요. 어느 이벤트가 그 잔액을 만들었는지는 분개 조회(STP-3200)에서 따라가요.

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP3300R01` | 시산표 | 없음 | trial |

## 그리드 `trial` 시산표

- 트랜잭션: `STP3300R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 상태 표시: 차대 일치 (`balanced`)
- 실시간: DB가 바뀌면 마지막 조회조건으로 다시 조회, 바뀐 칸 강조 (행 식별 열 `code`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `code` | 계정코드 | accounts_chart.code | 계정코드 | 코드 | 왼쪽 |  |  |
| `name` | 계정명 | accounts_chart.name | 계정명 | 문자 | 왼쪽 |  |  |
| `normal_side` | 정상잔액 방향 | accounts_chart.normal_side | 정상잔액 방향 (D 차변 / C 대변) | 코드 | 왼쪽 |  | 코드명(공통코드 `NORMAL_SIDE`) |
| `balance` | 잔액 | account_balances_v.balance | 잔액 | 금액 | 오른쪽 |  |  |
