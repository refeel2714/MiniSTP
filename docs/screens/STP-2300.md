# STP-2300 시세 점검

> 이 문서는 `src/ministp/ui/screens/STP-2300.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 대사·평가 > 시세 점검

## 목적

평가와 기준가에 쓴 종가가 믿을 만한지 봐요. 대사는 수량과 금액을 맞추지만 종가가 틀리면 대사는 맞는데 기준가가 틀려요. 왼쪽에서 기준일을 고르면 오른쪽에 그날 쓴 종가를 종목마다 전일 종가, 그날의 체결단가와 견준 결과가 나와요. 종가가 호가단위에 맞는지, 평가에 쓴 종가와 기준가에 쓴 종가가 같은지, 전일 대비 가격제한폭을 넘게 움직이지 않았는지를 확인하고, 확인이 필요한 날이 있으면 그날이 먼저 골라져 있어요. 오늘 종가가 아직 없으면 평가 전으로 맨 위에 보여요. 기준은 목록 위에 적혀 있어요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 34%): `days` 기준일
- 오른쪽: `prices` 종목별 종가

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP2300R01` | 기준일별 시세 점검 요약 | `date_from` (date), `date_to` (date) | days |
| `STP2300R02` | 기준일의 종목별 종가 점검 | `date` (date) | prices |

## 그리드 `days` 기준일

- 트랜잭션: `STP2300R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 상태 표시: 주의(전일 대비) (`warn_change`), 확인 필요(가격제한폭) (`limit_change`), 주의(체결단가와 종가) (`warn_exec_gap`)
- 실시간: DB가 바뀌면 마지막 조회조건으로 다시 조회, 바뀐 칸 강조 (행 식별 열 `date`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `date` | 기준일 | - | (화면 계산·집계 값) | 날짜 | 왼쪽 |  |  |
| `symbols` | 종목 수 | - | (화면 계산·집계 값) | 수량 | 오른쪽 |  |  |
| `flagged` | 확인 필요 | - | (화면 계산·집계 값) | 수량 | 오른쪽 |  |  |

| `result` | 결과 | - | (화면 계산·집계 값) | 문자 | 왼쪽 | 상태 | 상태 표시(둥근 표시) |

## 그리드 `prices` 종목별 종가

- 트랜잭션: `STP2300R02` → 데이터셋 `main`
- 불러오는 때: 목록(마스터)에서 행 선택
- 마스터: `days` (`date` ← `days.date`)
- 행 더블클릭·Enter: STP-3100로 이동 (`symbol` ← `symbol`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|

| `asset_type` | 자산 유형 | instruments.asset_type | 자산 유형 (STOCK / ETF) | 코드 | 왼쪽 |  | `instrument_name` 배지 안에 표시, 코드명(공통코드 `ASSET_TYPE`) |
