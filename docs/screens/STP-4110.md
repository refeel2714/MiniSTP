# STP-4110 시장 종목 마스터

> 이 문서는 `src/ministp/ui/screens/STP-4110.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 기준정보 > 종목

## 목적

시장에 상장된 전 종목(KIS 마스터 파일을 master load로 적재한 것)을 기준일 시점으로 보여줘요. 원장에 등록하지 않은 종목도 나와요. 가격은 담지 않아요(종가는 시세 STP-2300). 왼쪽에서 종목을 고르면 그날의 속성과 각 속성이 그 값이 된 날, 그리고 언제 무엇이 바뀌었는지가 오른쪽에 나와요. 변경 이력을 두 번 누르면 그날 바뀐 종목 전체(STP-4120)로 가요. 목록은 한 번에 500행까지라 조회조건으로 좁혀요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 44%): `market` 시장 종목
- 오른쪽: `attrs` 기준일의 종목 속성, `history` 속성 변경 이력

## 그리드 `market` 시장 종목

- 트랜잭션: `STP4110R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 상태 표시: 기준일 (`base_date`), 표시 (`shown`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `symbol` | 단축코드 | instrument_master.symbol | 단축코드 | 코드 | 왼쪽 |  | `name` 배지 안에 표시 |
| `sec_group` | 증권그룹 구분 | instrument_master.sec_group | 증권그룹 구분 (ST 주권, EF ETF 등) | 코드 | 왼쪽 |  | `name` 배지 안에 표시, 코드명(공통코드 `SECURITY_GROUP`) |
| `as_of` | 기준일 | - | (화면 계산·집계 값) | 날짜 | 왼쪽 |  | 숨김 (행 식별·연결에만 씀) |
| `name` | 종목명 | instrument_master.name | 종목명 | 문자 | 왼쪽 |  | 배지(이름 첫 글자, 색은 코드·모양은 자산 유형) |
| `market` | 시장 | instrument_master.market | 시장 (KOSPI / KOSDAQ) | 코드 | 왼쪽 |  | 코드명(공통코드 `MARKET`) |
| `state` | 상태 | - | (화면 계산·집계 값) | 문자 | 왼쪽 | 상태 | 상태 표시(둥근 표시) |
| `registered` | 원장 등록 | - | (화면 계산·집계 값) | 문자 | 왼쪽 | 상태 | 상태 표시(둥근 표시) |

## 그리드 `attrs` 기준일의 종목 속성

## 그리드 `history` 속성 변경 이력

- 트랜잭션: `STP4110R03` → 데이터셋 `main`
- 불러오는 때: 목록(마스터)에서 행 선택
- 마스터: `market` (`symbol` ← `market.symbol`, `date` ← `market.as_of`)
- 높이 비중: 2 (좌우 구성에서 같은 쪽 그리드와 나눠 쓰는 높이)
