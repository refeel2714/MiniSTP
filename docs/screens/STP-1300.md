# STP-1300 주문가능 조회

> 이 문서는 `src/ministp/ui/screens/STP-1300.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 주문·잔고 > 주문가능

## 목적

종목·매매구분·수량·지정가를 넣는 즉시 주문가능 여부를 판단해요. 판단은 실제 주문 검증(session.submit)과 같은 판단(R-36~38)을 백엔드에서 해서, 화면과 주문 결과가 어긋나지 않아요. 지정가가 없으면 최근 종가를 기준 단가로 써요. 종목코드는 찾기 버튼(F2)으로 등록 종목에서 골라요. 주문은 하지 않아요.

| 조건 | 한글명 | 형식 | DB 컬럼 | 필수 | 기본값 | 선택값 | 찾기 팝업 |

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP1300R02` | 주문가능 판단 | `symbol` (text), `side` (text), `qty` (int), `limit_price` (int) | check |
| `STP1300R01` | 종목별 주문가능 | 없음 | symbols |

## 그리드 `check` 주문가능 판단

- 트랜잭션: `STP1300R02` → 데이터셋 `main`
- 불러오는 때: 조회조건을 바꿀 때마다 (입력 즉시 재계산)
- 표시: 요약 카드
- 상태 표시: 주문 가능 (`ok`)
- 실시간: DB가 바뀌면 마지막 조회조건으로 다시 조회, 바뀐 칸 강조 (행 식별 열 `reason_text`)

| `reason_text` | 판단 | - | (화면 계산·집계 값) | 문자 | 왼쪽 | 판단(가능 초록/불가 빨강) |  |

## 찾기 팝업

입력 칸 옆 찾기 버튼(또는 F2)으로 여는 목록이에요. 여러 화면이 같은 정의(`lookups.yaml`)를 같이 써요.

| 이름 | 제목 | 조회 트랜잭션 | 고르면 들어가는 열 | 함께 보여 주는 열 | 목록의 열 |
|---|---|---|---|---|---|
| `symbol` | 종목 찾기 | `STP4100R01` | `symbol` | `instrument_name` | 종목코드(`symbol`), 종목명(`instrument_name`), 시장(`market`), 자산 유형(`asset_type`) |
