# STP-3200 분개 조회

> 이 문서는 `src/ministp/ui/screens/STP-3200.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 원장·회계 > 분개

## 목적

왼쪽에서 이벤트 하나를 고르면 그 이벤트가 만든 분개 전체를 오른쪽에 ERP 전표처럼 차변(계정·과목·금액)과 대변(계정·과목·금액)을 나란히 보여줘요. T계정이나 표로도 바꿔 볼 수 있어요. 전표 번호·회계일·전표 유형·원천은 전표마다 맨 왼쪽 칸에 따로 적고, 전표 사이는 점선으로 나누고, 차변 합계와 대변 합계가 맞는지를 합계 줄에 보여줘요. 이벤트를 두 번 누르면 그 이벤트의 보유·예수금 변동을 원장 조회(STP-3100)에서 열어요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 42%): `events` 분개를 만든 이벤트
- 오른쪽: `journal` 분개

## 그리드 `events` 분개를 만든 이벤트

- 트랜잭션: `STP3200R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 행 더블클릭·Enter: STP-3100로 이동 (`seq` ← `seq`)
- 실시간: DB가 바뀌면 마지막 조회조건으로 다시 조회, 바뀐 칸 강조 (행 식별 열 `seq`)

## 그리드 `journal` 분개

- 트랜잭션: `STP3200R02` → 데이터셋 `journal`
- 불러오는 때: 목록(마스터)에서 행 선택
- 마스터: `events` (`seq` ← `events.seq`)
- 표시: T계정 (계정 `account_code`마다 T 하나, 차변 `debit`은 왼쪽, 대변 `credit`은 오른쪽). 전표(`entry_id`)마다 묶고 그 아래에 차변 합계, 대변 합계와 대차 일치 여부를 보여요. 나머지 열은 묶음의 머리말에 나오고, 오른쪽 위에서 표로 바꿔 볼 수 있어요
- 합계: `debit`, `credit`
- 상태 표시: 차대 일치 (`balanced`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `entry_id` | 전표 번호 | journal_entries.entry_id | 전표 번호 | 수량 | 오른쪽 |  |  |

| `source_id` | 원천 참조 | journal_entries.source_id | 원천 참조 (체결번호 등) | 코드 | 왼쪽 |  |  |
| `account_code` | 계정코드 | journal_lines.account_code | 계정코드 | 코드 | 왼쪽 |  |  |
| `account_name` | 계정명 | accounts_chart.name | 계정명 | 문자 | 왼쪽 |  |  |

## 찾기 팝업

입력 칸 옆 찾기 버튼(또는 F2)으로 여는 목록이에요. 여러 화면이 같은 정의(`lookups.yaml`)를 같이 써요.

| 이름 | 제목 | 조회 트랜잭션 | 고르면 들어가는 열 | 함께 보여 주는 열 | 목록의 열 |
|---|---|---|---|---|---|
| `symbol` | 종목 찾기 | `STP4100R05` | `symbol` | `instrument_name` | 종목코드(`symbol`), 종목명(`instrument_name`), 시장(`market`), 자산 유형(`asset_type`) |
