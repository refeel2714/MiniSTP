# STP-3100 원장·분개 조회

> 이 문서는 `src/ministp/ui/screens/STP-3100.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

## 목적

왼쪽에서 원장 이벤트 하나를 고르면 그 이벤트가 만든 분개, 보유수량 변동, 예수금 변동을 오른쪽에 보여줘요. 분개는 차변을 왼쪽, 대변을 오른쪽에 둔 T계정으로 그리고 대차가 맞는지를 바로 아래에 보여줘요(표로도 바꿔 볼 수 있어요). 원장이 틀리지 않는다는 걸 숫자로 따라가 확인하는 화면이에요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 36%): `events` 원장 이벤트
- 오른쪽: `journal` 분개, `positions` 보유수량 변동, `cash` 예수금 변동
- 아래 (고른 행과 무관): `trial` 시산표

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP3100R01` | 원장 이벤트 목록 | `date_from` (date), `date_to` (date), `event_type` (text), `symbol` (text) | events |
| `STP3100R02` | 이벤트 추적 | `seq` (int) | journal, positions, cash |
| `STP3100R03` | 시산표 | 없음 | trial |

## 그리드 `journal` 분개

- 트랜잭션: `STP3100R02` → 데이터셋 `journal`
- 불러오는 때: 목록(마스터)에서 행 선택
- 마스터: `events` (`seq` ← `events.seq`)
- 높이 비중: 2 (좌우 구성에서 같은 쪽 그리드와 나눠 쓰는 높이)
- 표시: T계정 (계정 `account_code`마다 T 하나, 차변 `debit`은 왼쪽, 대변 `credit`은 오른쪽). 전표(`entry_id`)마다 묶고 그 아래에 차변 합계, 대변 합계와 대차 일치 여부를 보여요. 나머지 열은 묶음의 머리말에 나오고, 오른쪽 위에서 표로 바꿔 볼 수 있어요
- 합계: `debit`, `credit`
- 상태 표시: 차대 일치 (`balanced`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `entry_id` | 전표 번호 | journal_entries.entry_id | 전표 번호 | 수량 | 오른쪽 |  |  |
| `date` | 회계일 | journal_entries.date | 회계일 | 날짜 | 왼쪽 |  |  |
| `kind` | 전표 유형 | journal_entries.kind | 전표 유형 | 코드 | 왼쪽 |  |  |
| `source_id` | 원천 참조 | journal_entries.source_id | 원천 참조 (체결번호 등) | 코드 | 왼쪽 |  |  |
| `account_code` | 계정코드 | journal_lines.account_code | 계정코드 | 코드 | 왼쪽 |  |  |
| `account_name` | 계정명 | accounts_chart.name | 계정명 | 문자 | 왼쪽 |  |  |
| `debit` | 차변 금액 | journal_lines.debit | 차변 금액 | 금액 | 오른쪽 |  |  |
| `credit` | 대변 금액 | journal_lines.credit | 대변 금액 | 금액 | 오른쪽 |  |  |
| `reverses_entry_id` | 역분개 대상 전표 번호 | journal_entries.reverses_entry_id | 역분개 대상 전표 번호 | 수량 | 오른쪽 |  |  |

## 찾기 팝업

입력 칸 옆 찾기 버튼(또는 F2)으로 여는 목록이에요. 여러 화면이 같은 정의(`lookups.yaml`)를 같이 써요.

| 이름 | 제목 | 조회 트랜잭션 | 고르면 들어가는 열 | 함께 보여 주는 열 | 목록의 열 |

| `symbol` | 종목 찾기 | `STP4100R01` | `symbol` | `instrument_name` | 종목코드(`symbol`), 종목명(`instrument_name`), 시장(`market`), 자산 유형(`asset_type`), 최근 종가(`last_close`) |
