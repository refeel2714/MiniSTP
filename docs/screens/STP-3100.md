# STP-3100 원장·분개 조회

> 이 문서는 `src/ministp/ui/screens/STP-3100.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

## 목적

원장 이벤트 하나를 고르면 그 이벤트가 만든 분개, 보유수량 변동, 예수금 변동을 바로 아래에 보여줘요. 원장이 틀리지 않는다는 걸 숫자로 따라가 확인하는 화면이에요.

## 조회조건

| 조건 | 한글명 | 형식 | DB 컬럼 | 기본값 | 선택값 |
|---|---|---|---|---|---|
| `date_from` | 시작일 | date | - |  |  |
| `date_to` | 종료일 | date | - |  |  |
| `event_type` | 이벤트 유형 | select | ledger_events.event_type |  | DepositEvent, OpeningPositionEvent, ExecutionEvent, SettlementEvent, RevaluationEvent, NavEvent |
| `symbol` | 종목코드 | text | instruments.symbol |  |  |

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP3100R01` | 원장 이벤트 목록 | `date_from` (date), `date_to` (date), `event_type` (text), `symbol` (text) | events |
| `STP3100R02` | 이벤트 추적 | `seq` (int) | journal, positions, cash |
| `STP3100R03` | 시산표 | 없음 | trial |

## 그리드 `events` 원장 이벤트

- 트랜잭션: `STP3100R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 |
|---|---|---|---|---|---|---|
| `seq` | 이벤트 순번 | ledger_events.seq | 이벤트 순번 | 수량 | 오른쪽 |  |
| `event_type` | 이벤트 유형 | ledger_events.event_type | 이벤트 유형 | 코드 | 왼쪽 |  |
| `date` | 영업일 | - | (화면 계산·집계 값) | 날짜 | 왼쪽 |  |
| `symbol` | 종목코드 | instruments.symbol | 종목코드 | 코드 | 왼쪽 |  |
| `recorded_at` | 기록 시각 | ledger_events.recorded_at | 기록 시각 | 일시 | 왼쪽 |  |
| `payload` | 이벤트 내용 | ledger_events.payload | 이벤트 내용 | JSON | 왼쪽 |  |

## 그리드 `journal` 분개

- 트랜잭션: `STP3100R02` → 데이터셋 `journal`
- 불러오는 때: 마스터 행 선택
- 마스터: `events` (`seq` ← `events.seq`)
- 합계: `debit`, `credit`
- 상태 표시: 차대 일치 (`balanced`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 |
|---|---|---|---|---|---|---|
| `entry_id` | 전표 번호 | journal_entries.entry_id | 전표 번호 | 수량 | 오른쪽 |  |
| `date` | 회계일 | journal_entries.date | 회계일 | 날짜 | 왼쪽 |  |
| `kind` | 전표 유형 | journal_entries.kind | 전표 유형 | 코드 | 왼쪽 |  |
| `source_id` | 원천 참조 | journal_entries.source_id | 원천 참조 (체결번호 등) | 코드 | 왼쪽 |  |
| `account_code` | 계정코드 | journal_lines.account_code | 계정코드 | 코드 | 왼쪽 |  |
| `account_name` | 계정명 | accounts_chart.name | 계정명 | 문자 | 왼쪽 |  |
| `debit` | 차변 금액 | journal_lines.debit | 차변 금액 | 금액 | 오른쪽 |  |
| `credit` | 대변 금액 | journal_lines.credit | 대변 금액 | 금액 | 오른쪽 |  |
| `reverses_entry_id` | 역분개 대상 전표 번호 | journal_entries.reverses_entry_id | 역분개 대상 전표 번호 | 수량 | 오른쪽 |  |
