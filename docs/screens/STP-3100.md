# STP-3100 원장 조회

> 이 문서는 `src/ministp/ui/screens/STP-3100.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 원장·회계 > 원장

## 목적

왼쪽에서 원장 이벤트 하나를 고르면 그 이벤트가 바꾼 보유수량과 예수금을 오른쪽에 보여줘요. 원장에 무엇이 어떤 순서로 기록됐는지 따라가는 화면이에요. 이벤트를 두 번 누르면 그 이벤트가 만든 분개를 분개 조회(STP-3200)에서 열어요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 40%): `events` 원장 이벤트
- 오른쪽: `positions` 보유수량 변동, `cash` 예수금 변동

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP3100R01` | 원장 이벤트 목록 | `date_from` (date), `date_to` (date), `event_type` (text), `symbol` (text), `seq` (int) | events |
| `STP3100R02` | 이벤트의 보유·예수금 변동 | `seq` (int) | positions, cash |

## 그리드 `events` 원장 이벤트

- 트랜잭션: `STP3100R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 행 더블클릭·Enter: STP-3200로 이동 (`seq` ← `seq`)
- 실시간: DB가 바뀌면 마지막 조회조건으로 다시 조회, 바뀐 칸 강조 (행 식별 열 `seq`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `seq` | 이벤트 순번 | ledger_events.seq | 이벤트 순번 | 수량 | 오른쪽 |  |  |
| `event_type` | 이벤트 유형 | ledger_events.event_type | 이벤트 유형 | 코드 | 왼쪽 |  | 코드명(공통코드 `EVENT_TYPE`) |
| `date` | 영업일 | - | (화면 계산·집계 값) | 날짜 | 왼쪽 |  |  |
| `symbol` | 종목코드 | instruments.symbol | 종목코드 | 코드 | 왼쪽 |  |  |
| `recorded_at` | 기록 시각 | ledger_events.recorded_at | 기록 시각 | 일시 | 왼쪽 |  |  |
| `payload` | 이벤트 내용 | ledger_events.payload | 이벤트 내용 | JSON | 왼쪽 |  |  |

- 불러오는 때: 목록(마스터)에서 행 선택
- 마스터: `events` (`seq` ← `events.seq`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `trade_date` | 매매일 | position_ledger.trade_date | 매매일 | 날짜 | 왼쪽 |  |  |
| `symbol` | 종목코드 | position_ledger.symbol | 종목코드 | 코드 | 왼쪽 |  |  |
| `exec_id` | 체결 ID | position_ledger.exec_id | 체결 ID (계좌 안에서 유일, 기초 보유는 OPEN-종목코드) | 코드 | 왼쪽 |  |  |
| `qty_delta` | 수량 증감 | position_ledger.qty_delta | 수량 증감 | 수량 | 오른쪽 | 부호(+빨강/-파랑) |  |
| `cost_delta` | 장부금액 증감 | position_ledger.cost_delta | 장부금액 증감 | 금액 | 오른쪽 | 부호(+빨강/-파랑) |  |
| `realized_pnl` | 실현손익 | position_ledger.realized_pnl | 실현손익 | 금액 | 오른쪽 | 부호(+빨강/-파랑) |  |

## 찾기 팝업

입력 칸 옆 찾기 버튼(또는 F2)으로 여는 목록이에요. 여러 화면이 같은 정의(`lookups.yaml`)를 같이 써요.

| 이름 | 제목 | 조회 트랜잭션 | 고르면 들어가는 열 | 함께 보여 주는 열 | 목록의 열 |
|---|---|---|---|---|---|
| `symbol` | 종목 찾기 | `STP4100R05` | `symbol` | `instrument_name` | 종목코드(`symbol`), 종목명(`instrument_name`), 시장(`market`), 자산 유형(`asset_type`) |
