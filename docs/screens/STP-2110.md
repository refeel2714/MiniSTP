# STP-2110 원장 내부 대사

> 이 문서는 `src/ministp/ui/screens/STP-2110.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 대사·평가 > 대사

## 목적

저장된 잔고와 분개가 원장 이벤트를 처음부터 다시 계산한 값과 같은지를 항목별로 보여줘요. 증권사와 맞추는 일일 대사(STP-2100)가 바깥과의 대사라면 이 화면은 원장 안에서의 대사예요. 왼쪽에서 점검 항목을 고르면 오른쪽에 판정과, 저장된 값과 맞아야 하는 값을 나란히 놓은 비교가 나와요. 터미널의 verify 명령과 같은 점검이고 읽기만 해요. 불일치가 있으면 그 항목이 먼저 골라져 있어요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 30%): `checks` 점검 항목
- 오른쪽: `verdict` 판정, `compared` 값 비교

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP2110R01` | 원장 점검 항목 | 없음 | checks |
| `STP2110R02` | 점검 항목의 판정과 값 비교 | `title` (text) | verdict, compared |

## 그리드 `checks` 점검 항목

- 트랜잭션: `STP2110R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 상태 표시: 모두 일치 (`all_ok`), 불일치 수 (`breaks`)
- 실시간: DB가 바뀌면 마지막 조회조건으로 다시 조회, 바뀐 칸 강조 (행 식별 열 `key`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `title` | 점검 항목 | - | (화면 계산·집계 값) | 문자 | 왼쪽 |  |  |
| `result` | 결과 | - | (화면 계산·집계 값) | 문자 | 왼쪽 | 상태 | 상태 표시(둥근 표시) |
| `key` | 점검 코드 | - | (화면 계산·집계 값) | 코드 | 왼쪽 |  | 숨김 (행 식별·연결에만 씀) |

## 그리드 `verdict` 판정

- 트랜잭션: `STP2110R02` → 데이터셋 `check`
- 불러오는 때: 목록(마스터)에서 행 선택
- 마스터: `checks` (`title` ← `checks.title`)
- 표시: 요약 카드

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `result` | 결과 | - | (화면 계산·집계 값) | 문자 | 왼쪽 | 상태 |  |
| `detail` | 판정 내용 | - | (화면 계산·집계 값) | 문자 | 왼쪽 |  |  |

## 그리드 `compared` 값 비교

- 트랜잭션: `STP2110R02` → 데이터셋 `rows`
