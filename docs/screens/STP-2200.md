# STP-2200 기준가·무오류 현황

> 이 문서는 `src/ministp/ui/screens/STP-2200.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

## 목적

일별 순자산과 기준가(1,000좌당) 추이, Phase 2 게이트(20영업일 연속 무오류) 진행을 봐요. 기준가는 원장을 그날 상태로 재현해 계산해요.

## 그리드 `nav` 기준가 추이

- 트랜잭션: `STP2200R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 상태 표시: 무오류 연속 영업일 (`clean_streak`), 게이트 목표 (`gate_days`)
- 실시간: DB가 바뀌면 마지막 조회조건으로 다시 조회, 바뀐 칸 강조 (행 식별 열 `date`)
- 차트: `date` 대비 `nav_per_1000` 선 그래프
