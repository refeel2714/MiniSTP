# STP-1200 주문·체결 블로터

> 이 문서는 `src/ministp/ui/screens/STP-1200.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 주문·잔고 > 주문·체결

## 목적

왼쪽에서 주문마다 전송 → 접수 → 체결 → 결제 가운데 어디까지 왔는지 한 줄로 보고, 주문을 고르면 오른쪽에 접수 내용과 체결별 결제 예정일·결제일이 나와요. 결재 요청으로 나간 주문은 요청 번호(바스켓은 3-2처럼 줄 번호까지)가 붙고, 오른쪽 아래에 그 요청의 모든 줄과 체결률이 나와요. 결제는 예수금 화면과 같은 원장에서 읽어요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 58%): `orders` 주문
- 오른쪽: `order` 접수 내용, `fills` 체결과 결제, `lines` 같은 요청의 줄
