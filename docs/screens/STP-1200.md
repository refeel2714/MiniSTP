# STP-1200 주문·체결 블로터

> 이 문서는 `src/ministp/ui/screens/STP-1200.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

## 목적

주문 의도 → 증권사 접수 → 원장 반영 체결을 한 줄로 보고, 체결통보가 원장에 반영되기까지 걸린 시간을 확인해요.

## 조회조건

| 조건 | 한글명 | 형식 | DB 컬럼 | 기본값 | 선택값 |
|---|---|---|---|---|---|
| `day` | 주문일 | date | oms_orders.trade_date | today |  |

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP1200R01` | 주문·체결 블로터 | `day` (date) | orders |

## 그리드 `orders` 주문

- 트랜잭션: `STP1200R01` → 데이터셋 `main`
- 불러오는 때: 조회 버튼
- 합계: `filled_amount`
- 행 더블클릭·Enter: STP-3100로 이동 (`symbol` ← `symbol`)
