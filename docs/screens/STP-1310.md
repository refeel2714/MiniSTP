# STP-1310 바스켓 주문 시뮬레이션

> 이 문서는 `src/ministp/ui/screens/STP-1310.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 주문·잔고 > 주문 준비

## 목적

이번 주문의 배분 비율과 총 주문금액을 넣으면 종목별 수량을 계산해요(R-97). 배분 비율은 총 주문금액을 종목에 나누는 비율(합계 100%)이에요. 계좌 전체의 목표 편입비가 아니에요. 한 번 주문하는 금액이 계좌 평가금액보다 훨씬 작으면 한 번에 목표 편입비를 맞출 수 없어서, 주문 결과로 비중이 어떻게 되는지는 "주문 후 비중"으로 봐요. 처음에는 지금 보유 종목이 현재 편입비(보유 평가금액 비중, 예수금 제외) 비율 그대로 들어가 있고(그대로 사면 비중 유지), 배분 비율을 고치면 오른쪽이 바로 다시 계산돼요. 수량은 배분 금액 ÷ 주문가를 1주 단위로 내리고, 주문가는 현재가를 호가단위에 맞춘 값이에요. 검사는 묶음 검증(R-98)이 해요. 주문 전 검증과 같은 기준(R-36~38)으로 앞 줄을 보냈다고 친 채 다음 줄을 보고, 종목당 비중 한도는 매수에만(미체결 매수 포함) 걸어요. 계산만 하고 DB에 쓰지 않으며 주문도 내지 않아요(결재와 전송은 게이트 뒤). 같은 계산을 `basket simulate` 명령으로 CSV로 저장할 수 있어요.

## 화면 구성

좌우 구성이에요. 왼쪽에 입력하면 오른쪽이 그 값으로 다시 계산돼요.

- 왼쪽 (너비 36%): `basket` 바스켓
- 오른쪽: `plan` 종목별 주문안, `summary` 요약

## 조회조건

| 조건 | 한글명 | 형식 | DB 컬럼 | 필수 | 기본값 | 선택값 | 찾기 팝업 |
|---|---|---|---|---|---|---|---|
| `amount` | 총 주문금액 | number | - | 예 | 10000000 |  |  |
| `side` | 매매구분 | select | oms_orders.side | 예 | BUY | BUY, SELL |  |
| `basis` | 주문가 | select | - | 예 | 현재가 지정가 | 현재가 지정가, 현재가 +1호가, 시장가 |  |
| `limit` | 종목당 한도(%) | number | - |  | 30 |  |  |

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP1310R01` | 바스켓 (현재 편입비) | 없음 | basket |
| `STP1310R02` | 종목별 주문안 | `amount` (int), `side` (text), `basis` (text), `limit` (int), `basket` (text) | plan, summary |

## 그리드 `basket` 바스켓

- 트랜잭션: `STP1310R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 입력: `target_weight` 칸에 값을 넣어요 (저장하지 않음). 처음 값과 되돌아갈 값은 `current_weight`. 고친 칸은 주황 테두리와 원래 값이 보이고, 그 칸의 ↺를 누르면 그 행만 되돌아가요. 그리드 오른쪽 위 `↺ 현재 편입비로` 버튼은 모든 행을 되돌려요. 행 추가는 찾기 팝업 `symbol`로 골라요. 넣은 값은 `basket` 조건(`행키:값,…`)으로 오른쪽 그리드에 가요
- 합계: `current_weight`, `target_weight`
- 상태 표시: 현재 편입비 기준 (`basis`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `symbol` | 종목코드 | instruments.symbol | 종목코드 | 코드 | 왼쪽 |  | `instrument_name` 배지 안에 표시 |
| `instrument_name` | 종목명 | instruments.name | 종목명 | 문자 | 왼쪽 |  | 배지(이름 첫 글자, 색은 코드·모양은 자산 유형) |
| `asset_type` | 자산 유형 | instruments.asset_type | 자산 유형 (STOCK / ETF) | 코드 | 왼쪽 |  | `instrument_name` 배지 안에 표시 |
| `current_weight` | 현재 편입비(%) | - | (화면 계산·집계 값) | 비율·단가 | 오른쪽 |  |  |
| `target_weight` | 배분 비율(%) | - | (화면 계산·집계 값) | 비율·단가 | 오른쪽 |  |  |
| `price` | 현재가 | - | (화면 계산·집계 값) | 금액 | 오른쪽 |  |  |

- 불러오는 때: 조회조건을 바꿀 때마다 (입력 즉시 재계산)
- 높이 비중: 3 (좌우 구성에서 같은 쪽 그리드와 나눠 쓰는 높이)
- 합계: `target_amount`, `amount`, `actual_weight`, `costs`
- 상태 표시: 계산 기준 (`basis`), 종목당 한도 (`limit`)
