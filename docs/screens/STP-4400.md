# STP-4400 계좌 목록

> 이 문서는 `src/ministp/ui/screens/STP-4400.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

## 목적

왼쪽에서 위탁계좌를 고르면 오른쪽에 그 계좌의 보유와 상태 이력이 나와요. 화면을 열면 위쪽 막대에서 고른 계좌가 먼저 골라져 있고, 더블클릭하면 그 계좌의 계좌정보(STP-4200)로 가요. 계좌번호와 인증키는 DB에 없고 이 화면에도 나오지 않아요. 등록과 상태 변경은 CLI(customer, account 명령)로만 해요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 45%): `accounts` 위탁계좌
- 오른쪽: `positions` 이 계좌의 보유, `status_history` 이 계좌의 상태 이력

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP4400R01` | 계좌 목록 | 없음 | accounts |
| `STP4400R03` | 계좌 보유 | `account_id` (text) | positions |
| `STP4400R02` | 계좌 상태 이력 | `account_id` (text) | status_history |

## 그리드 `accounts` 위탁계좌

- 트랜잭션: `STP4400R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 합계: `cash_d0`, `book_cost`
- 행 더블클릭·Enter: STP-4200로 이동 (계좌 ← `account_id`)
- 실시간: DB가 바뀌면 마지막 조회조건으로 다시 조회, 바뀐 칸 강조 (행 식별 열 `account_id`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `account_id` | 계좌 ID | trading_accounts.account_id | 계좌 ID | 코드 | 왼쪽 |  |  |
| `alias` | 계좌 별칭 | trading_accounts.alias | 계좌 별칭 | 문자 | 왼쪽 |  |  |
| `customer_alias` | 고객 별칭 | customers.alias | 고객 별칭 | 문자 | 왼쪽 |  |  |
| `status` | 현재 상태 | account_status_v.status | 현재 상태 | 코드 | 왼쪽 | 상태 |  |
| `cash_d0` | 예수금 D+0 | - | (화면 계산·집계 값) | 금액 | 오른쪽 |  |  |
| `book_cost` | 보유 장부금액 | - | (화면 계산·집계 값) | 금액 | 오른쪽 |  |  |

## 그리드 `positions` 이 계좌의 보유

- 트랜잭션: `STP4400R03` → 데이터셋 `main`
- 불러오는 때: 목록(마스터)에서 행 선택
- 마스터: `accounts` (`account_id` ← `accounts.account_id`)
- 높이 비중: 2 (좌우 구성에서 같은 쪽 그리드와 나눠 쓰는 높이)
- 합계: `book_cost`

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `instrument_name` | 종목명 | instruments.name | 종목명 | 문자 | 왼쪽 |  | 배지(이름 첫 글자, 색은 코드·모양은 자산 유형) |
| `symbol` | 종목코드 | positions_v.symbol | 종목코드 | 코드 | 왼쪽 |  | `instrument_name` 배지 안에 표시 |
| `asset_type` | 자산 유형 | instruments.asset_type | 자산 유형 (STOCK / ETF) | 코드 | 왼쪽 |  | `instrument_name` 배지 안에 표시 |
| `qty` | 보유수량 | positions_v.qty | 보유수량 | 수량 | 오른쪽 |  |  |
| `book_cost` | 장부금액 | positions_v.book_cost | 장부금액 (매입금액) | 금액 | 오른쪽 |  |  |
