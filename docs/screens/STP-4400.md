# STP-4400 고객·계좌

> 이 문서는 `src/ministp/ui/screens/STP-4400.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

## 목적

고객과 위탁계좌의 목록, 계좌 상태 이력, 고객별 보유 합산을 보여줘요. 계좌번호와 인증키는 DB에 없고 이 화면에도 나오지 않아요. 인증정보 참조는 PC 환경변수 이름의 머리말일 뿐이에요. 계좌를 고르면 상태 이력이 아래에 나오고, 더블클릭하면 그 계좌의 계좌정보로 가요. 다른 화면은 위쪽 막대에서 고른 계좌 하나만 보여줘요. 등록과 상태 변경은 CLI(customer, account 명령)로만 해요.

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP4400R01` | 고객·계좌 목록 | 없음 | accounts |
| `STP4400R02` | 계좌 상태 이력 | `account_id` (text) | status_history |
| `STP4400R03` | 고객별 보유 합산 | 없음 | customer_positions |

## 그리드 `accounts` 위탁계좌

- 트랜잭션: `STP4400R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 합계: `cash_d0`, `book_cost`
- 행 더블클릭·Enter: STP-4200로 이동 (계좌 ← `account_id`)
- 실시간: DB가 바뀌면 마지막 조회조건으로 다시 조회, 바뀐 칸 강조 (행 식별 열 `account_id`)

## 그리드 `status_history` 이 계좌의 상태 이력

- 트랜잭션: `STP4400R02` → 데이터셋 `main`
- 불러오는 때: 마스터 행 선택
- 마스터: `accounts` (`account_id` ← `accounts.account_id`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 |
|---|---|---|---|---|---|---|
| `status` | 상태 | account_status_history.status | 상태 (OPEN 정상 / SUSPENDED 정지 / CLOSED 해지) | 코드 | 왼쪽 | 상태 |
| `effective_from` | 적용 시작일 | account_status_history.effective_from | 적용 시작일 | 날짜 | 왼쪽 |  |
| `reason` | 사유 | account_status_history.reason | 사유 | 문자 | 왼쪽 |  |
| `created_at` | 기록 시각 | account_status_history.created_at | 기록 시각 | 일시 | 왼쪽 |  |
