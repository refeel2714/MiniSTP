# STP-1100 실시간 잔고

> 이 문서는 `src/ministp/ui/screens/STP-1100.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 주문·잔고 > 잔고

## 목적

장중 보유·예수금·주문가능금액(IBOR)을 한 화면에서 확인해요. 종목별 보유는 구성 지도로 바꿔 보면 어느 종목이 얼마나 큰지(면적)와 평가손익(색)이 한눈에 보여요. 주문가능금액은 주문 검증과 같은 계산(R-37)이에요.

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP1100R02` | 예수금·주문가능금액 | 없음 | cash |
| `STP1100R01` | 종목별 보유 | `day` (date) | holdings |

## 그리드 `cash` 예수금과 주문가능금액

- 트랜잭션: `STP1100R02` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 표시: 요약 카드
- 실시간: DB가 바뀌면 마지막 조회조건으로 다시 조회, 바뀐 칸 강조 (행 식별 열 `cash_d0`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `cash_d0` | 예수금 D+0 | - | (화면 계산·집계 값) | 금액 | 오른쪽 |  |  |
| `projected_cash` | 결제 후 예수금 | - | (화면 계산·집계 값) | 금액 | 오른쪽 |  |  |
| `pending_buy_value` | 미체결 매수 예약 | - | (화면 계산·집계 값) | 금액 | 오른쪽 |  |  |
| `available_cash` | 주문가능금액 | - | (화면 계산·집계 값) | 금액 | 오른쪽 |  |  |
| `unpriced_buy_orders` | 가격 미정 시장가 매수 | - | (화면 계산·집계 값) | 수량 | 오른쪽 |  |  |

## 그리드 `holdings` 종목별 보유

- 트랜잭션: `STP1100R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 바꿔 보기: 구성 지도 (행 하나가 타일 하나, 이름 `instrument_name`, 면적 `book_cost`, 색 `unrealized_pnl`: 면적 값 대비 +는 빨강, -는 파랑, 값이 없으면 빗금). 그리드 머리의 버튼으로 표와 바꿔 보고, 타일을 누르면 그 행이 골라져요
- 합계: `book_cost`
- 행 더블클릭·Enter: STP-3100로 이동 (`symbol` ← `symbol`)
- 실시간: DB가 바뀌면 마지막 조회조건으로 다시 조회, 바뀐 칸 강조 (행 식별 열 `symbol`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `symbol` | 종목코드 | instruments.symbol | 종목코드 | 코드 | 왼쪽 |  | `instrument_name` 배지 안에 표시 |
| `instrument_name` | 종목명 | instruments.name | 종목명 | 문자 | 왼쪽 |  | 배지(이름 첫 글자, 색은 코드·모양은 자산 유형) |
| `asset_type` | 자산 유형 | instruments.asset_type | 자산 유형 (STOCK / ETF) | 코드 | 왼쪽 |  | `instrument_name` 배지 안에 표시, 코드명(공통코드 `ASSET_TYPE`) |
| `qty` | 보유수량 | positions_v.qty | 보유수량 | 수량 | 오른쪽 |  |  |
| `book_cost` | 장부금액 | positions_v.book_cost | 장부금액 (매입금액) | 금액 | 오른쪽 |  | 셀 안 막대(열의 최댓값 대비) |
| `weight` | 비중 | - | (화면 계산·집계 값) | 비율·단가 | 왼쪽 |  | 비율 막대(%) |
| `trend` | 최근 종가 추세 | - | (화면 계산·집계 값) | 숫자열 | 왼쪽 |  | 추세선(오래된 값부터) |
| `today_qty` | 오늘 체결 수량 | - | (화면 계산·집계 값) | 수량 | 오른쪽 | 부호(+빨강/-파랑) |  |
| `market_value` | 평가금액(최근 종가) | - | (화면 계산·집계 값) | 금액 | 오른쪽 |  | 숨김 (행 식별·연결에만 씀) |
| `unrealized_pnl` | 평가손익(최근 종가) | - | (화면 계산·집계 값) | 금액 | 오른쪽 | 부호(+빨강/-파랑) | 숨김 (행 식별·연결에만 씀) |
