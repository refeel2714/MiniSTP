# STP-4100 종목정보

> 이 문서는 `src/ministp/ui/screens/STP-4100.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

## 목적

등록된 종목의 기본정보와, 시스템이 실제로 쓰는 값(최근 종가의 호가단위, 매도 세율)을 함께 보여줘요. 왼쪽에서 종목을 고르면 그 종목의 원장 이벤트가 오른쪽에 나오고, 더블클릭하면 주문가능 조회로 가요. 종목 등록·변경은 지금은 CLI(instrument 명령)로만 해요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 55%): `instruments` 등록 종목
- 오른쪽: `events` 이 종목의 원장 이벤트

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP4100R01` | 종목정보 | 없음 | instruments |
| `STP4100R02` | 종목 원장 이벤트 | `symbol` (text) | events |

## 그리드 `instruments` 등록 종목

- 트랜잭션: `STP4100R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 행 더블클릭·Enter: STP-1300로 이동 (`symbol` ← `symbol`)
- 실시간: DB가 바뀌면 마지막 조회조건으로 다시 조회, 바뀐 칸 강조 (행 식별 열 `symbol`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 |
|---|---|---|---|---|---|---|
| `symbol` | 종목코드 | instruments.symbol | 종목코드 | 코드 | 왼쪽 |  |
| `instrument_name` | 종목명 | instruments.name | 종목명 | 문자 | 왼쪽 |  |
| `market` | 시장 | instruments.market | 시장 (KOSPI / KOSDAQ) | 코드 | 왼쪽 |  |
| `asset_type` | 자산 유형 | instruments.asset_type | 자산 유형 (STOCK / ETF) | 코드 | 왼쪽 |  |
| `last_close` | 최근 종가 | - | (화면 계산·집계 값) | 금액 | 오른쪽 |  |
| `close_date` | 종가 기준일 | - | (화면 계산·집계 값) | 날짜 | 왼쪽 |  |
| `tick` | 호가단위(종가 기준) | - | (화면 계산·집계 값) | 금액 | 오른쪽 |  |
| `sell_tax` | 매도 세율(거래세+농특세) | - | (화면 계산·집계 값) | 문자 | 왼쪽 |  |
| `qty` | 보유수량 | positions_v.qty | 보유수량 | 수량 | 오른쪽 |  |
| `book_cost` | 장부금액 | positions_v.book_cost | 장부금액 (매입금액) | 금액 | 오른쪽 |  |

## 그리드 `events` 이 종목의 원장 이벤트

- 트랜잭션: `STP4100R02` → 데이터셋 `main`
- 불러오는 때: 목록(마스터)에서 행 선택
- 마스터: `instruments` (`symbol` ← `instruments.symbol`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 |
|---|---|---|---|---|---|---|
| `seq` | 이벤트 순번 | ledger_events.seq | 이벤트 순번 | 수량 | 오른쪽 |  |
| `event_type` | 이벤트 유형 | ledger_events.event_type | 이벤트 유형 | 코드 | 왼쪽 |  |
| `date` | 업무일자 | - | (화면 계산·집계 값) | 날짜 | 왼쪽 |  |
| `recorded_at` | 기록 시각 | ledger_events.recorded_at | 기록 시각 | 일시 | 왼쪽 |  |
| `payload` | 이벤트 내용 | ledger_events.payload | 이벤트 내용 | JSON | 왼쪽 |  |
