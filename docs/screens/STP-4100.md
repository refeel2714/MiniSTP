# STP-4100 종목정보

> 이 문서는 `src/ministp/ui/screens/STP-4100.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 기준정보 > 종목

## 목적

등록된 종목의 기본정보를 보여줘요. 기준정보는 어느 계좌를 보든 같은 값만 담아요. 그래서 보유수량과 장부금액은 잔고(STP-1100)에, 종가는 시세(STP-2300)에, 종목의 원장 이벤트는 원장 조회(STP-3100)에 있어요. 왼쪽에서 종목을 고르면 그 종목을 거래할 때 적용되는 기준(수수료, 매도 세금, 결제주기, 호가단위)이 오른쪽에 나오고, 더블클릭하면 주문가능 조회로 가요. 종목 등록·변경은 지금은 CLI(instrument 명령)로만 해요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 50%): `instruments` 등록 종목
- 오른쪽: `rules` 이 종목에 적용되는 거래 기준

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP4100R01` | 종목정보 | 없음 | instruments |
| `STP4100R02` | 종목에 적용되는 거래 기준 | `symbol` (text) | rules |

## 그리드 `instruments` 등록 종목

- 트랜잭션: `STP4100R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 행 더블클릭·Enter: STP-1300로 이동 (`symbol` ← `symbol`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `symbol` | 종목코드 | instruments.symbol | 종목코드 | 코드 | 왼쪽 |  | `instrument_name` 배지 안에 표시 |
| `instrument_name` | 종목명 | instruments.name | 종목명 | 문자 | 왼쪽 |  | 배지(이름 첫 글자, 색은 코드·모양은 자산 유형) |
| `market` | 시장 | instruments.market | 시장 (KOSPI / KOSDAQ) | 코드 | 왼쪽 |  |  |
| `asset_type` | 자산 유형 | instruments.asset_type | 자산 유형 (STOCK / ETF) | 코드 | 왼쪽 |  | `instrument_name` 배지 안에 표시 |
| `sell_tax` | 매도 세율(거래세+농특세) | - | (화면 계산·집계 값) | 문자 | 왼쪽 |  |  |

## 그리드 `rules` 이 종목에 적용되는 거래 기준

- 트랜잭션: `STP4100R02` → 데이터셋 `main`
- 불러오는 때: 목록(마스터)에서 행 선택
- 마스터: `instruments` (`symbol` ← `instruments.symbol`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `kind` | 구분 | - | (화면 계산·집계 값) | 문자 | 왼쪽 |  |  |
| `item` | 항목 | - | (화면 계산·집계 값) | 문자 | 왼쪽 |  |  |
| `value` | 값 | - | (화면 계산·집계 값) | 문자 | 왼쪽 |  |  |
| `note` | 비고 | - | (화면 계산·집계 값) | 문자 | 왼쪽 |  |  |
