# STP-4100 종목정보

> 이 문서는 `src/ministp/ui/screens/STP-4100.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 기준정보 > 종목

## 목적

시장에 상장된 전 종목과 원장에 등록한 종목을 한 목록으로 보여줘요. 시장 종목은 KIS 마스터 파일을 master load로 적재한 이력에서 기준일 시점의 값을 꺼내요(가격은 담지 않아요. 종가는 시세 STP-2300). 등록 종목은 원장이 거래하는 종목이라 맨 위에 오고, 대조 결과는 등록한 이름·시장·자산 유형이 기준일의 마스터와 같은지예요. 왼쪽에서 종목을 고르면 그날의 속성이 오른쪽에 두 줄 양식으로 나와요. 주요 항목(종목명, 시장, 증권그룹, 거래 상태, 상장일)이 먼저 오고, 값 아래 작은 글씨는 그 값이 된 날이에요. 거래정지·정리매매·관리종목·시장경고·상장 여부는 '거래 상태' 한 줄로 모았어요. 언제 무엇이 바뀌었는지는 속성을 두 번 눌러 이 종목을 마지막으로 바꾼 적재 이력(STP-4101)에서 보고, 거래할 때 적용되는 기준(수수료, 매도 세금, 결제주기, 호가단위)은 거래 기준(STP-4300)에서 봐요. 등록 종목을 두 번 누르면 주문가능 조회로 가요. 목록은 한 번에 500행까지라 조회조건으로 좁혀요. 종목 등록·변경은 지금은 CLI(instrument 명령)로만 해요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 44%): `instruments` 종목
- 오른쪽: `attrs` 기준일의 종목 속성

## 그리드 `instruments` 종목

- 트랜잭션: `STP4100R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 상태 표시: 기준일 (`base_date`), 표시 (`shown`)
- 행 더블클릭·Enter: `opens` 열이 가리키는 화면(STP-1300)으로 이동 (`symbol` ← `symbol`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `symbol` | 단축코드 | instrument_master.symbol | 단축코드 | 코드 | 왼쪽 |  | `name` 배지 안에 표시 |
| `sec_group` | 증권그룹 구분 | instrument_master.sec_group | 증권그룹 구분 (ST 주권, EF ETF 등) | 코드 | 왼쪽 |  | `name` 배지 안에 표시, 코드명(공통코드 `SECURITY_GROUP`) |
