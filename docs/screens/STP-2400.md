# STP-2400 마감 점검

> 이 문서는 `src/ministp/ui/screens/STP-2400.yaml`에서 생성돼요. 직접 고치지 말고 화면 정의를 고친 뒤 `python scripts/gen_screen_docs.py`를 실행하세요.

분류: 대사·평가 > 마감 점검

## 목적

하루 작업이 어디까지 끝났고 무엇이 남았는지를 한곳에서 봐요. 왼쪽에서 영업일을 고르면 오른쪽에 그날의 작업이 하는 순서대로(결제, 주문·체결, 시세, 기준가, 증권사 대사, 일 마감, 원장 내부 대사) 한 줄씩 나오고, 줄마다 상태와 그렇게 본 까닭이 적혀 있어요. 완료와 대상 없음은 끝난 단계, 대기는 오늘 아직 하지 않은 단계, 주의는 끝났지만 한번 볼 단계, 확인 필요는 누가 판단해야 하는 단계, 누락은 날이 지났는데 하지 않은 단계예요. 줄을 두 번 누르면 그 단계의 상세 화면이 그날로 열려요. 원장 내부 대사는 그날이 아니라 지금 원장의 상태예요. 모든 단계는 위쪽에서 고른 계좌의 것이에요.

## 화면 구성

좌우 구성이에요. 왼쪽 목록에서 행을 고르면 오른쪽이 그 행의 상세로 바뀌어요.

- 왼쪽 (너비 32%): `days` 영업일
- 오른쪽: `steps` 하루 작업 단계

## 트랜잭션

| 트랜잭션 | 이름 | 조회조건 | 쓰는 그리드 |
|---|---|---|---|
| `STP2400R01` | 영업일별 마감 점검 요약 | `date_from` (date), `date_to` (date) | days |
| `STP2400R02` | 영업일의 작업 단계별 상태 | `date` (date) | steps |

## 그리드 `days` 영업일

- 트랜잭션: `STP2400R01` → 데이터셋 `main`
- 불러오는 때: 화면 열 때 + 조회 버튼
- 상태 표시: 확인이 필요한 날 (`attention_days`)
- 실시간: DB가 바뀌면 마지막 조회조건으로 다시 조회, 바뀐 칸 강조 (행 식별 열 `date`)

| 열 | 한글명 | DB 컬럼 | DB 주석 | 형식 | 정렬 | 색 | 표시 |
|---|---|---|---|---|---|---|---|
| `date` | 영업일 | - | (화면 계산·집계 값) | 날짜 | 왼쪽 |  |  |
| `done` | 끝난 단계 | - | (화면 계산·집계 값) | 수량 | 왼쪽 |  | 비율 막대(`steps` 대비, 값 / 전체) |
| `steps` | 전체 단계 | - | (화면 계산·집계 값) | 수량 | 오른쪽 |  | `done` 막대 안에 표시 |
| `attention` | 확인 필요 | - | (화면 계산·집계 값) | 수량 | 오른쪽 |  | 숨김 (행 식별·연결에만 씀) |
| `state` | 상태 | - | (화면 계산·집계 값) | 문자 | 왼쪽 | 상태 | 상태 표시(둥근 표시) |

## 그리드 `steps` 하루 작업 단계

- 트랜잭션: `STP2400R02` → 데이터셋 `main`
- 불러오는 때: 목록(마스터)에서 행 선택
- 마스터: `days` (`date` ← `days.date`)
- 행 더블클릭·Enter: `screen` 열이 가리키는 화면(STP-3400, STP-1200, STP-2300, STP-2210, STP-2100, STP-2200, STP-2110)으로 이동 (`day` ← `date`, `date_from` ← `date`, `date_to` ← `date`)
