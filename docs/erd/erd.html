MiniSTP ERD

v1.0테이블 11개 · 컬럼 67개 · 뷰 3개스키마 해시 c47db189f7b8

백오피스 연계 매매 시스템의 PostgreSQL 스키마예요. DB에서 직접 읽어 만들었고, 한글 명칭은 DB 주석(COMMENT)이라 pgAdmin에서도 똑같이 보여요. 원장 테이블은 모두 수정·삭제가 막혀 있고(append-only), 정정은 새 행으로 남겨요.

관계도

PK 기본키 FK 외래키 UK 유일키 ‖──< 1 : N (한 행이 여러 행에 연결) · 키 컬럼만 그렸고, 상자를 누르면 전체 컬럼으로 이동해요.
